# SCPshow
Prints the file content of a given SCP index from the official wiki.
# USAGE
scpshow [index of SCP]

Optional: Parse to file with scpshow [index of SCP] >file.txt

# INSTALLATION

Compile with the given ./compile bash script

Move the newly created scpshow binary to your /usr/bin/bash or other executable path.

# DEPENDENCIES

-gcc
-lynx
